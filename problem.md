# Problem

People organizing small gaming tournaments, sports competitions, or other events
often struggle to manage brackets and keep track of match results. When there are
multiple competitors and rounds, manually organizing matchups, tracking winners,
and determining who advances can become confusing and time-consuming.

# Initial requirements

- R1. Allow the organizer to create a tournament with a custom name.
- R2. Allow the organizer to add competitors to the tournament.
- R3. Generate a randomized single-elimination bracket using the competitors.
- R4. Automatically assign byes when the number of competitors does not fill a
  complete bracket.
- R5. Display the matchups for each round.
- R6. Allow the organizer to enter match results and advance winners to the next
  round.
- R7. Display the tournament champion once all matches are completed.
- R8. Save and load tournament progress using local files.
